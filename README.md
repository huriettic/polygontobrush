# Polygon to brush



Convert a Marathon 2 polygon to Unreal Tournament 99 brush.



## How to use



Enter the name of the map without the sceA.



Enter the level number starting at zero.



Enter the directory path the map is in.



Enter the path where you want to save the brushes.



It outputs obj files and polygon files of separate polygons.



Update Unreal Tournament 99 with the latest patch then import the obj as brushes.
